# Curated exclusion list for CRUX `core` packages not needed in headless CI containers.
# One package name per line; comments (#) and blank lines are ignored.
# Pass `--full-core` to scripts/extract-rootfs.sh to install every CRUX core package instead.
#
# Note: `eudev` and `kmod` are intentionally KEPT because `util-linux` depends on `eudev`.
# Full build/CI toolchains (gcc, binutils, make, cmake, meson, ninja, python3, perl,
# curl, openssl, ca-certificates, libarchive, xz, zstd, pkgutils, ports, httpup, rsync,
# openssh, bash, dash, etc.) are intentionally KEPT.
